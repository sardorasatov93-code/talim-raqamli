# Hissa qo'shish

Rahmat! Har qanday yordam qadrlanadi.

- **Xato topdingizmi?** Issues bo'limida yangi issue oching: nima qildingiz, nima kutdingiz, nima bo'ldi.
- **Yangi shablon taklifi?** Issue'da shablon matnini (shaxsiy ma'lumotlarsiz!) yozing.
- **Kod o'zgartirish?** Repozitoriyni fork qiling, o'zgartiring va Pull request yuboring.

Qoidalar:
- Haqiqiy fuqarolarning shaxsiy ma'lumotlarini (F.I.Sh., manzil, telefon, pasport) hech qachon yuklamang.
- Vositalar internetsiz, faqat brauzerda ishlashi kerak — tashqi serverga ma'lumot yubormang.
- Matnlar o'zbek tilida (lotin yozuvida).
