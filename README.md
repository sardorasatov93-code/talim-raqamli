# Ta'lim raqamli — ta'lim sohasi uchun ochiq raqamli vositalar

**Ta'lim raqamli** — ta'lim muassasalari va ta'lim boshqaruvi xodimlarining kundalik qog'oz ishlarini
raqamlashtirish uchun bepul, ochiq kodli vositalar to'plami. Barcha vositalar **brauzerda ishlaydi**:
o'rnatish, server yoki internet talab qilinmaydi, ma'lumotlar kompyuteringizdan tashqariga chiqmaydi.

> 🇬🇧 *Free, open-source, browser-only tools that digitize routine paperwork in Uzbekistan's education
> sector (citizen appeal responses, official letters). No installation, no server, data stays local.*

## Vositalar

| Vosita | Holati | Tavsif |
|---|---|---|
| [Javob xati generatori](index.html) | ✅ Tayyor | Fuqarolar murojaatiga rasmiy javob xatini shakl orqali tayyorlaydi va chop etadi / PDF qiladi |
| Bildirgi generatori | 🔜 Rejada | Ichki bildirgi (xizmat xati) shabloni |
| Murojaatlar reestri | 🔜 Rejada | Kelgan murojaatlarni ro'yxatga olish, muddatlarni kuzatish (CSV eksport) |

## Qanday ishlatiladi

1. `index.html` faylini brauzerda oching (yoki loyihaning GitHub Pages sahifasiga kiring).
2. Chap tomondagi shaklni to'ldiring: murojaatchi, murojaat raqami va sanasi, javob mazmuni.
3. O'ng tomonda xat tayyor ko'rinishda chiqadi.
4. **Chop etish / PDF** tugmasini bosing — brauzer oynasida "PDF sifatida saqlash"ni tanlang.

Kiritilgan ma'lumotlar faqat brauzeringizda saqlanadi (localStorage), hech qayerga yuborilmaydi.

## Nega bu kerak

Ta'lim boshqaruvi organlariga har oy yuzlab murojaatlar keladi. Ularning ko'pchiligiga javob xati bir xil
tuzilishda yoziladi, lekin har safar qo'lda Word'da tahrirlanadi — bu vaqt oladi va xatoga olib keladi
(noto'g'ri raqam, sana, F.I.Sh.). Ushbu vositalar takroriy ishni shaklga aylantiradi.
